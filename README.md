I'm a BCA graduate and full-stack developer who ships complete applications end to end — schema, API, auth, UI. Lately I've been deep in **AI-powered systems**: LangGraph orchestration, prompt engineering, and evaluation pipelines.

- 🔭 Currently building **AIVOA** — an AI-powered complaint management system on LangGraph + FastAPI
- 🧪 Working as an **AI Data Annotator @ Handshake AI**, writing multi-hop fact-verification workflows
- 🌱 Currently deepening **Next.js, Drizzle ORM, and LLM evaluation techniques**
- 💬 Ask me about full-stack architecture, RBAC/auth design, or prompt engineering
